Authorize.Net is a payment gateway that sits in front of your own merchant account.

<Info>
  Payment processors are configured in **Settings → Integrations → Payment Gateway → Configure**,
  which opens the **Payment Gateways** page. See
  [Payment gateways](/settings/integrations) for the full picture.
</Info>

---

## What BeRocker asks for

| Field | Where it is |
| --- | --- |
| **Login ID** | Authorize.Net → Account → API Credentials & Keys. |
| **Transaction Key** | Generated on the same screen. |
| **Signature Key** | Generated on the same screen. |
| **Source Key** | The Accept.js client key, used for the secure card form. |

---

## Set the default and the fee

Authorize.Net does not report card funding directly, but its Accept.js response exposes the card
BIN, which BeRocker resolves — so it **can** honour a credit-cards-only processing fee.

<Warning>
  Authorize.Net payment links **expire after 15 minutes** and can only be paid once. A link an agent
  sent half an hour ago is a dead URL — send a fresh one.
</Warning>

The **Payment fee (%)** on the Payment Gateways page is added on top of what you charge:

- Empty or **0** → no fee. Charging $200 bills the customer exactly **$200.00**.
- **3** → a 3% fee. Charging $200 bills the customer **$206.00** ($200 + $6 fee).

Only the fee of the processor set as your **default card payment option** is applied — it does not
depend on which card the customer has. The customer sees the breakdown on the charge screen and on
the emailed receipt.
