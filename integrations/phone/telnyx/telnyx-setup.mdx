Telnyx is a virtual phone system for calls and SMS. Connecting it to BeRocker takes four values from
the Telnyx Portal.

<Info>
  Do the [account verification](/integrations/phone/telnyx/telnyx-account-verification) first.
  A trial account cannot send production traffic.
</Info>

---

## What you need from Telnyx

From the [Telnyx Portal](https://portal.telnyx.com/):

| Value | Where it is |
| --- | --- |
| **API Key** | API Keys. Create one if you have none. |
| **Public Key** | The account's public key — used to verify inbound webhooks. |
| **Messaging Profile ID** | Messaging → Messaging Profiles, on the profile your numbers belong to. BeRocker can list these for you once the API Key is accepted. |
| **Connection ID** | Voice → SIP Connections, on the connection you will call from. BeRocker can list these for you too. |

<Warning>
  The API key is a credential for your whole Telnyx account. Paste it into BeRocker and nowhere else.
</Warning>

---

## Connect it

<Steps>
  <Step title="Open Integrations">
    **Settings → Integrations** → **Communications** → **Telnyx → Configure**. The dialog is called
    **Update Telnyx settings**.
  </Step>
  <Step title="Paste the API Key and Public Key, set Status to Active, click Apply">
    **Messaging Profile ID** and **Connection ID** can be left empty at this point — or pasted in
    now if you already know them, in which case the next two steps are skipped.
  </Step>
  <Step title="Select the Messaging Profile ID and click Apply">
    Once the API Key is accepted, **Messaging Profile ID** turns into a dropdown
    (**Select Messaging Profile ID**) listing the profiles on your account. Pick the one your
    numbers belong to and click **Apply** again.
  </Step>
  <Step title="Select the Connection ID and click Apply">
    **Connection ID** now becomes a dropdown (**Select Connection ID**) of your SIP connections.
    Pick the one you call from and click **Apply** a third time. BeRocker registers its webhooks on
    the account automatically.
  </Step>
  <Step title="Check the card">
    It should show **Status: Active** in green.
  </Step>
  <Step title="Point your number at it">
    **Settings → Profile → User Contacts → Add user contact** → your Telnyx number with
    **Provider = Telnyx**, **Channel = Call/SMS (same number)** (saves one Call and one SMS contact
    in one go), **Status = Active**, and tick **Is Default?**.

    → [Profile](/settings/profile)
  </Step>
</Steps>

## Before you send at volume

US application-to-person SMS needs **10DLC registration**. Without it, carriers filter your messages
and they simply stop arriving.

→ [Telnyx 10DLC setup](/integrations/phone/telnyx/telnyx-10dlc-setup)

## Troubleshooting

| Symptom | Check |
| --- | --- |
| Apply fails with "Could not setup Telnyx, please check your credentials." | A wrong or rotated API key, or the wrong Public Key. Regenerate the key in the Telnyx Portal and paste the new one. |
| Status stays **Not connected** | The configuration was never saved — the last Apply was not completed. |
| Calls fail, texts work | The **Connection ID** is wrong, or the number is not on that connection. |
| Texts fail, calls work | The **Messaging Profile ID** is wrong, or the number is not on that profile. |
| Messages send but never arrive | 10DLC registration, then [Messaging health](/settings/messaging-health). |
| Inbound messages never appear | The **Public Key** is wrong, so inbound webhooks fail verification. |
